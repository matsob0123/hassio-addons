# SpotiFLAC (Deprecated)

This add-on has been deprecated and is no longer maintained.

## Reason

The upstream `ghcr.io/iassis/spotiflac` image (~840 MB) proved too difficult to
reliably build and run inside the Home Assistant Supervisor environment.

## Files preserved for reference

All source files (Dockerfile, run.sh, nginx.conf, apparmor.txt, config.yaml)
are kept here for historical reference only. Do not install this add-on.
